# Credits

Before was originally built by Veer Singh and [Will](https://github.com/willzhang100) at the YC × Medplum hackathon in August 2026. This repository contains the polished guided presentation and the local live workflow.

The live voice integration and prerecorded demo voices use Deepgram. The live evidence store uses Medplum. Vapi supports the optional phone leg. ElevenLabs is not currently integrated.

The case, witness accounts, and guided presentation data are synthetic. The four additional calls in the ending are a scripted concept reveal.
